# 机房音量管理 v0.4.1

Windows 10/11 机房音量管理工具。教师端查看座位音量、控制监测和管理学生机；学生端自动连接并采集音量统计，不保存录音。

## 使用

1. 教师机解压教师端包，双击 **启动教师端.cmd**。完成系统授权后自动打开管理页面，本机无需密码。
2. 将启动入口旁生成的 **学生端安装包.zip** 发到学生机。
3. 学生机解压后双击 **启动学生端.cmd**。
4. 教师页面点 **学生机 → 开启接入**，核对座位并批准。
5. 返回 **音量监控**，点击 **开始监测**。首次使用会自动校准，保持安静约 10 秒。

暂停、继续、结束和重新校准都在音量监控页。学生端不需要配对码或勾选许可。

## 压缩包结构

教师端：

```text
启动教师端.cmd
使用说明.txt
程序/
学生端安装包.zip    ← 首次启动时自动生成
```

学生端：

```text
启动学生端.cmd
使用说明.txt
程序/
```

只需双击最外层的中文启动入口。“程序”文件夹保存运行所需文件，无需手动操作，请保留完整目录。

两端首次运行后登记当前账户的登录自启。启动时显示中文进度，授权后自动继续，临时失败最多尝试 3 次。取消系统授权后可点“重新尝试”。

学生端登录自启后直接收进右下角托盘，任务栏不显示窗口。关闭或最小化窗口会收回托盘，双击托盘图标可打开窗口；右键托盘图标选“退出（需要密码）”并验证维护密码后，客户端和守护程序一同正常退出，其他进程退出会由守护程序重新启动。退出使用教师保管的维护密码（验证时教师机需在线），保存在教师端 `程序/data/initial-password.txt`。本机教师页面无需使用这个密码。普通用户态守护无法代替 Windows 账户权限管理。

建议给教师机设置固定局域网地址。地址或证书变化后，重新分发新生成的学生端安装包。升级请解压到新文件夹；需要保留旧版教师数据时，将旧版 `data` 目录复制到新版 `程序/data` 后再启动。

## 开发与打包

需要 Windows、.NET 10 SDK、Node.js 22 及 npm。

```powershell
.\scripts\build.ps1
```

输出：`artifacts/机房音量管理-教师端-v0.4.1-win-x64.zip`、`artifacts/机房音量管理-学生端-v0.4.1-win-x64.zip`。

```powershell
dotnet test RoomScope.slnx
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/startup-smoke.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/launcher-smoke.ps1
```

设备接口保留独立凭证和教师审批。教师本机回环访问免登录，其他电脑远程访问教师页面仍需验证。镜像部署辅助脚本在学生端“程序”目录中，管理员操作参考 IMAGE-DEPLOYMENT.md。
