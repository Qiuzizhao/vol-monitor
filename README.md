# 声域 RoomScope v0.3.1

用于机房区域噪声监测的局域网研究原型。Windows 学生端读取麦克风，在本机计算音量特征；教师端接收统计并显示座位分布、区域指数、实时趋势和实验记录。

**不保存或上传原始音频，不进行语音内容识别，不包含摄像头或专注度推断。** 噪声指数表示相对背景音的变化，不是实际声压级，也不能用于判断个人纪律。

## 已实现

- Windows 学生端：麦克风选择、设备配对、教师统一控制采集、可见状态、断线停采和重连。
- 教师端：管理登录、10 分钟配对码、设备撤销、座位绑定。
- 镜像部署：通用地址配置、独立硬件摘要和设备凭证、自动申请、教师批量批准与座位绑定、克隆身份检查。
- 实验控制：真实 / 模拟实验隔离、开始、暂停、恢复、结束、安静基线校准。
- 音量计算：RMS、电平峰值、削波比例、基线校正、时间平滑、区域 P70 和持续超标提示。
- 研究看板：座位分布、区域覆盖、120 秒趋势、人工活动标注、实验档案。
- SQLite 持久化、区域 CSV 和完整实验 JSON 导出。

## 最简单的使用方式（推荐）

新版运行包把地址、证书和学生端配置合并到双击启动流程：

1. **教师机**：解压教师包，双击 `start-teacher.cmd`。自动识别局域网地址、配置 HTTPS；多个网卡时只需选课堂使用的网络。首次运行按 Windows 提示确认信任证书、允许防火墙配置（需要管理员授权）。浏览器自动打开，初始密码也会在记事本中打开。
2. **分发学生包**：把教师目录自动生成的 `RoomScope-classroom-student.zip` 发给学生机。包内已带教师地址和公开证书，不含教师密码、私钥或设备身份。
3. **学生机**：解压这个学生包，双击 `start-student.cmd`，首次确认 Windows 证书提示。默认选择系统麦克风并自动申请接入，无需输入 IP 或配对码。
4. **教师确认**：看板 → 设备管理 → 镜像批量接入，开启接入窗口，核对座位后批量批准。教师开始真实实验并点击安静校准，学生端自动采集，无需勾选。

首次成功运行后，教师端和课堂学生端都会登记当前账户的登录自启，无需每次手动启动。教师端登录后在后台启动，再次双击入口即可打开看板。已批准的学生设备自动重连，学生端重新启动后自动等待教师指令，无需人工勾选。请保留完整解压目录，教师目录应由同一 Windows 账户运行；请只分发生成的学生 ZIP，不要分发教师目录。

课堂学生包默认启用受管模式：不显示托盘图标，关闭窗口仅最小化到任务栏；再次双击入口可重新打开窗口。守护程序在学生进程正常退出、崩溃或被结束后自动重启，重试间隔为 2～30 秒。教师可在学生窗口点“教师维护退出”，输入教师看板密码，在线验证后同时停止客户端和守护程序，本次登录期间不再重启；下次登录或手动启动后恢复。Windows 注销和关机不会触发重启。音量采集由教师开始、暂停和结束实验统一控制。

这里的“开机自启”是登录对应 Windows 账户后启动，不是在登录前运行。受管模式限制客户端内的退出操作；它无法阻止具有系统权限的人同时结束守护进程、删除启动项或修改程序。若需防止学生从系统层面绕过，请使用标准学生账户，并由学校管理员将程序目录设为学生只读、配合账户或机房管理策略。教师端的自启可在 Windows“启动应用”中关闭 `RoomScopeTeacher`；学生端对应 `RoomScopeAgent`。

建议给教师机保留固定 IP。教师 IP 改变或证书临近到期时，入口会更新连接配置；需要重新分发新生成的学生包，由教师维护退出旧客户端后解压新包并双击启动。手动启动时控制台需要保持打开，关闭后教师服务停止。

以下手动配置流程保留供已有部署和学校管理员使用。

## 机房镜像部署（可选）

镜像批量安装优先使用 [IMAGE-DEPLOYMENT.md](IMAGE-DEPLOYMENT.md) 中的流程，无需在每台学生机输入配对码。

在学生端目录运行 `prepare-image.ps1 -TeacherServer 'https://192.168.1.10:5081' -EnableLoginStartup`，生成通用配置并清理母盘身份。随后封装镜像，克隆后的学生机各自申请接入；教师在“设备管理 → 镜像批量接入”开启窗口、核对座位并批准。

还原卡清除身份文件后，学生机会重新申请，教师确认后可以沿用硬件对应的座位。可使用 `-IdentityDirectory 'D:\RoomScopeState'` 将身份放在不还原的本地分区，但仍需同一账户及可用的 Windows DPAPI 密钥。设备接入后保持待机，只有教师开始真实实验才会自动采集音量。

## 直接使用 Windows 运行包

教师端和学生端均提供 Windows x64 自包含运行包，无需另装 .NET、Node.js 或 Python。解压到当前 Windows 账户有写权限的目录。此版目标环境是 Windows 10/11 x64；旧版 Windows 不在本版支持范围内。

### 1. 在教师机预览

解压教师端，双击 `start-local.cmd`，浏览器打开 `http://127.0.0.1:5080`。首次登录密码在教师端 `data/initial-password.txt`，运行期间保留服务控制台。

进入看板后选择“体验模拟实验”。模拟数据由程序生成，不访问任何麦克风，其中包含一个模拟离线座位。真实学生机在模拟模式下保持待机。

本机 HTTP 模式只用于预览。其他电脑接入需要下述 HTTPS 配置。

### 2. 配置局域网 HTTPS

以下命令在**教师端解压目录**的 PowerShell 中执行。先为教师机设置固定局域网 IPv4 地址，再将示例 IP 改成实际地址：

```powershell
.\configure-https.ps1 -ServerIp 192.168.1.10 -Port 5081
.\start-lan.ps1
```

配置脚本在当前账户证书库生成一年有效的证书，导出公开证书 `roomscope-teacher.cer`，将私钥和由 Windows DPAPI 保护的证书密码保存在教师端 `data`。脚本将此目录权限限制为当前账户。之后应使用相同 Windows 账户启动教师端。

在教师机和各学生机的**实际运行账户**中导入公开证书，路径按实际文件位置填写：

```powershell
Import-Certificate -FilePath .\roomscope-teacher.cer -CertStoreLocation Cert:\CurrentUser\Root
```

只分发 `.cer` 公钥证书，不分发教师端 `data`、`.pfx` 或密码文件。证书到期或教师机 IP 变化时需要重新配置并分发证书。教师机防火墙需允许课堂子网访问 TCP 5081；脚本不会自动修改防火墙。

若学校已有受信任的内部 CA，可直接使用学校签发的证书，按 ASP.NET Core Kestrel 标准环境变量配置证书和监听地址。

### 3. 接入学生机

1. 在教师看板的“设备管理”中点击“接入设备”，取得配对码。
2. 学生机解压学生端，启动 `Noise.Agent.exe`。
3. 输入 `https://192.168.1.10:5081`、设备名称和配对码，选择麦克风，点击“配对并连接”。
4. 教师端为每台设备绑定座位。一个座位只能绑定一台真实设备。
5. 学生端自动等待教师指令，无需勾选采集许可。
6. 教师创建真实实验，再点击“安静校准”，保持背景相对安静约 10 秒。校准成功后显示指数。

手动配对的非受管客户端最小化后留在系统托盘，关闭窗口或退出程序会停止采集；受管模式的关闭与重启行为见上方推荐流程。教师暂停 / 结束实验时，客户端在下一次成功通信时停止；网络异常则在请求失败或超时后停止。单次网络请求超时为 5 秒，失败重试间隔逐步增长至 30 秒。

学生端配置默认位于 `%LOCALAPPDATA%/RoomScope/agent.json`，设备令牌使用当前 Windows 账户的 DPAPI 加密并绑定本机硬件摘要。配置不能直接复制到其他账户或电脑。镜像模式可指定独立身份目录。新启动时会选择仍存在的已保存麦克风；其已消失则选当前默认麦克风，需要重新校准。

### 4. 实验与导出

- 实时看板点击“添加标注”，记录讲解、讨论、测试音源等事件。
- 点击“暂停”会清除实时值和连续提示计时，历史数据保留。
- “实验记录”可导出区域 CSV，包含每 5 秒的区域快照、有效设备数、模式、模拟标记和算法参数。
- 实验 JSON 额外包含设备快照、相关校准记录、座位结构和人工 / 系统标注。模拟设备的基线是固定的 `-65 dBFS`，其 `baselineId` 为 `demo`，没有真实校准记录。
- 服务重启后，先前未结束的实验标记为结束，不会自动恢复采集；设备绑定和校准记录仍保留。

## 算法与数据含义

算法版本：`rms-baseline-p70-v1`。

| 环节 | 当前实现 |
| --- | --- |
| 音频输入 | WASAPI 原生格式；支持 16/24/32 位 PCM、32 位浮点 |
| 采集处理 | 约 100 ms 回调内累加能量，不保留音频块 |
| 音量统计 | 每秒按平均能量计算 RMS 电平，另算峰值和削波比例 |
| 背景基线 | 10 个有效秒级电平的中位数；全零或无效输入不用于校准 |
| 平滑 | 秒级电平指数平滑，系数 0.35；长时间断流后重新初始化 |
| 噪声指数 | `clamp((平滑电平 - 基线 - 3) / 27 × 100, 0, 100)` |
| 区域指数 | 有效设备指数的第 70 百分位数，线性插值 |
| 有效覆盖 | 至少 3 台，且不少于区域座位数的一半，才允许触发提示 |
| 提示触发 | 安静模式 ≥70 / 讨论模式 ≥85，连续 5 秒 |
| 提示解除 | 比触发阈值低 20 点，持续 3 秒 |
| 数据过期 | 超过 3 秒无有效统计；超过 10 秒无设备报告则离线 |
| 持久化 | 每 5 秒保存当前有效设备和区域的**快照**，不是 5 秒均值 |

基线会按设备和麦克风标识保存，换麦克风不会套用另一支麦克风的基线。调节输入增益、改变耳麦位置或课堂背景后，应主动重新校准。当前版本不自动检测增益设置变化，也不在课堂期间自适应抬高背景基线。

不同型号的麦克风、自动增益、收音方向和摆放高度仍会影响区域比较。尽量统一设备及位置，并通过可控音源实验验证。多个麦克风可能收到同一声音，系统不识别声音来源或说话者。

实时页面只保留最近 120 个秒级点。教师端数据库会保留统计数据，**当前原型没有自动过期清理功能**，研究人员应按实验要求导出、归档或删除数据。

## 源码与开发

```text
src/Noise.Core/       音量计算、区域算法、提示状态机、通信契约
src/Noise.Agent/      Windows WinForms + WASAPI 学生端
src/Noise.Server/     ASP.NET Core、鉴权、SQLite、实验控制、WebSocket
web/                 Vue 3 + TypeScript 教师看板
tests/Noise.Tests/    音频数学、设备 / 实验状态、HTTP 接口测试
scripts/             Windows 打包、预览和 HTTPS 部署脚本
```

开发需要 .NET 10 SDK、Node.js 22 或更新的受支持版本，以及 npm。

```bash
npm ci --prefix web
npm run build --prefix web
dotnet test RoomScope.slnx
dotnet run --project src/Noise.Server
```

打开 `http://127.0.0.1:5080`。从源码运行时，默认数据目录位于 `src/Noise.Server/data`。

前端热更新可以另开终端运行 `npm run dev --prefix web`，Vite 会将 API 和 WebSocket 转发到教师服务。最终运行包使用编译后的本地静态文件，不依赖 Vite。

Windows 构建与打包：

```powershell
.\scripts\build.ps1
```

输出到 `artifacts/RoomScope-teacher-v0.3.1-win-x64.zip` 和 `artifacts/RoomScope-student-v0.3.1-win-x64.zip`。学生端受管模式测试需要 Windows；源码可交叉发布 Windows 包，但 Windows 麦克风及 GUI 行为必须在 Windows 实机上验证。

### 教室设置

教师端 `appsettings.json` 可修改 `Room.Name`、`Room.Rows`、`Room.Columns`。默认 6×6、36 座位，按前 / 中 / 后和左 / 右划为 6 区。行数支持 3～20，列数支持 2～16 的偶数。

座位结构只在空数据库首次启动时初始化。已有数据库不会因修改行列配置自动重排；改变机房布局需先归档现有数据，再使用新的数据目录初始化。

可用环境变量 `DataDirectory` 指定数据目录。`TeacherPassword` 仅在首次创建教师凭据时生效，至少 10 个字符；已有凭据不会被环境变量覆盖。自动生成的初始密码文件可在妥善保管密码后删除，实际验证使用加盐 PBKDF2 哈希。

## 核心接口

教师接口使用登录 Cookie。修改操作必须携带 `X-RoomScope: 1`；设备接口使用独立 Bearer 令牌。局域网 API 拒绝明文 HTTP，只有回环地址允许用于调试。

| 接口 | 用途 |
| --- | --- |
| `POST /api/login` | 教师登录 |
| `GET /api/teacher/dashboard` | 当前看板状态 |
| `GET /api/teacher/pairing` | 获取 10 分钟有效的配对码 |
| `POST /api/devices/enroll` | 配对注册 |
| `GET /api/enrollment` | 查询是否开放批量接入 |
| `POST /api/device-requests` | 学生机申请接入，使用独立 Enrollment 凭证 |
| `GET /api/device-requests/{id}` | 使用该申请的凭证查询处理状态 |
| `GET /api/teacher/enrollment` | 教师查看待接入设备及座位建议 |
| `POST /api/teacher/enrollment/{open,close}` | 开关 10 分钟接入窗口 |
| `POST /api/teacher/enrollment/approve` | 批量批准并绑定座位 |
| `PUT /api/teacher/devices/{id}/seat` | 绑定座位 |
| `DELETE /api/teacher/devices/{id}` | 移除设备并撤销令牌 |
| `POST /api/telemetry` | 上报统计并取得采集指令 |
| `POST /api/teacher/sessions` | 创建实验 |
| `POST /api/teacher/sessions/current/{pause,resume,end}` | 控制实验 |
| `POST /api/teacher/calibrations` | 发起安静校准 |
| `POST /api/device/calibration` | 提交设备基线 |
| `POST /api/teacher/annotations` | 添加实验标注 |
| `GET /api/teacher/sessions/{id}/export.csv` | 区域统计导出 |
| `GET /api/teacher/sessions/{id}/experiment.json` | 完整实验导出 |
| `GET /ws/dashboard` | 经教师鉴权的实时看板推送 |

设备上报的 JSON 字段受严格约束，未知字段会被拒绝，单次请求上限为 8 KB。接口不接收音频文件。日志不记录请求体、设备令牌或登录密码。

## 实机验证建议

先在 3～6 台、包含最老配置的机房电脑上验证：麦克风权限与热插拔、原生采样格式、暂停 / 断网停采、CPU 和内存占用、区域收音差异。使用无人教室和可控音源检查区域结果，再开展真实课堂实验。

当前原型提供镜像准备、当前账户登录启动和批量登记；未集成学校镜像分发工具、还原卡管理、安装向导、多教室管理或自动历史数据清理。自包含 ZIP 可直接解压运行。低性能开销是设计目标，具体 CPU、内存和区域判断效果需要现场测量。
