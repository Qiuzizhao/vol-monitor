# 机房音量管理 v0.8.4

Windows 10/11 机房音量管理工具。教师端查看座位音量和管理学生机；学生端自动连接并采集音量统计，不保存录音。

## 使用

1. 教师机解压教师端包，双击 **启动教师端.cmd**。完成系统授权后自动打开管理页面，本机无需密码。
2. 页面点 **学生机管理 → 生成学生端**，首次设置维护密码（位数自定）后，下载 **学生端安装包.zip** 发到学生机。
3. 学生机解压后双击 **启动学生端.cmd**。
4. 学生机连接后按实际局域网 IP 自动加入列表并优先分配空座位，可在 **学生机管理** 中调整。
5. 接入后自动持续监测，无需开始或暂停。直接显示系统麦克风输入音量，无需校准，数字不设 100 上限。弱信号门槛降至采集统计下限，显示增益为 10 倍，数字可达几百、上千；静音仍归零，颜色和进度条按相同增益调整。

监控页只保留座位音量和布局，讲台位于座位区最下方，按教师面对学生的视角查看。监控页和布局编辑表格会根据窗口宽高及行列数自动调整格子、间距和字号，完整显示整班布局，无需上下滚动。教师端启动后自动运行，重启后自动恢复，新设备和更换麦克风后直接采集，不减去环境基线；学生机页用于座位分配和移除，无需开启接入或逐台批准。学生端状态窗口只显示电脑名称和状态，右键托盘只有退出。学生端不需要配对码或勾选许可。

## 座位布局

点击「座位布局」，像表格一样填写座位号。空格、空行和空列保留为走廊，可从 Excel 粘贴。拖选 A1、A2 两个格子后，拖动选区右下角的小方块，可向右或向下自动填充 A3、A4……；支持 Shift 扩选、Ctrl+A 全选、选区复制粘贴和 Delete 清空。移动相同座位号保留学生机绑定；删除已绑定座位会解除该设备的座位绑定。学生机列表直接显示连接教师端的 IP，同一 IP 始终视为同一设备，重启、重装或本地凭证丢失不会重复添加，沿用教师端保存的座位；IP 变化后按新设备处理。多台学生机可以分配同一座位，调整或交换时无需先腾空；重复期间座位格只显示「座位重复」，不显示音量；解除重复后自动恢复音量显示，悬停可查看各台 IP。学生机列表点击「学生机 IP」按地址数字排序，再点反向；点击「座位」可切回座位排序。点击「顺序匹配」，按 IP 升序将全部学生机（含离线）依次分配到按名称自然排序的座位，如 1、2、10 或 A1、A2、A10、B1；这会替换原有座位安排，座位不足时提示且不修改。

## 压缩包结构

教师端：

```text
启动教师端.cmd
使用说明.txt
程序/
```

课堂专用的 `学生端安装包.zip` 在教师页面生成，保存到浏览器下载位置。

学生端：

```text
启动学生端.cmd
使用说明.txt
程序/
```

只需双击最外层的中文启动入口。“程序”文件夹保存运行所需文件，无需手动操作，请保留完整目录。

教师端登录后自动运行，服务就绪后自动用默认浏览器打开管理网页（http://127.0.0.1:5080）；网络未就绪时持续自动重试，恢复后再打开页面。学生端首次启动或升级时申请一次管理员授权，自动接管旧客户端并安装到 `C:\Program Files\RoomScope\Student`，由 Windows 系统服务开机启动、在各学生账户登录后运行托盘客户端。之后无需保留解压目录。启动失败可点「查看启动记录」查看原因；教师服务原始异常另存于 `程序/data/运行错误.log`，系统守护错误位于 `C:\ProgramData\RoomScope\Guard\运行错误.log`。

学生端登录后直接收进右下角托盘，任务栏不显示窗口。关闭或最小化窗口会收回托盘；右键托盘选择“退出”，验证维护密码后才真正退出，系统服务为本次 Windows 登录记住合法退出。客户端或普通守护进程被结束会重新拉起，系统服务异常由 Windows 恢复策略重启。双击安装入口可重新运行，重新登录或重启也会恢复。学生账户应使用普通用户权限；Windows 管理员仍有停止服务和卸载软件的权限。

**维护密码只用于学生端退出，局域网教师页面和学生连接均不需要密码。** 设置和修改密码仍仅允许在教师机本机页面操作，避免学生从其他电脑重设退出密码。密码位数自定，不留空，两次输入一致即可；验证时教师机需在线。自定义密码只保存加盐摘要，不写入安装包或明文文件。

建议给教师机设置固定局域网地址。v0.8 使用稳定的机房根证书签发连接证书，连接证书续期无需重装学生端。旧版本学生端需更新一次，安装系统守护并信任机房根证书；教师端升级会保留尚未到期的旧连接证书，便于分批更新。教师机地址变更或机房根证书更换时，重新生成学生包升级即可，旧教师地址离线也能由管理员完成升级。

升级只需解压到新文件夹，双击 **启动教师端.cmd**：自动关闭检测到的旧版教师端，接替登录自启；新版尚无配置时，自动沿用检测到的旧版设备、座位、维护密码和证书。旧目录保留，已有新版配置不会被覆盖。旧版没有运行且没有自启记录时，可将旧版 `程序/data` 和 `程序/roomscope-teacher.cer` 复制到新版对应位置再启动。重复打开已经运行的同一版本会直接打开页面，不重启服务。

## 开发与打包

需要 Windows、.NET 10 SDK、Node.js 22 及 npm。

```powershell
.\scripts\build.ps1
```

输出：`artifacts/机房音量管理-教师端-v0.8.4-win-x64.zip`、`artifacts/机房音量管理-学生端-v0.8.4-win-x64.zip`。

```powershell
dotnet test RoomScope.slnx
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/startup-smoke.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/launcher-smoke.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/teacher-upgrade-smoke.ps1
```

学生机按连接来源 IP 自动识别和加入，不依赖本地连接凭证或教师审批；旧版学生端申请接口会直接返回自动连接结果。局域网访问不使用维护密码，公网地址和跨站请求不获得教师权限。系统守护按照 [Windows 服务与交互会话机制](https://learn.microsoft.com/en-us/windows/win32/services/interactive-services) 将界面运行在学生会话中。镜像准备参考 IMAGE-DEPLOYMENT.md。
